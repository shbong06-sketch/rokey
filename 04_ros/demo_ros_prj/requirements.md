# 공장 다중로봇 관제 시스템 프로젝트 내용

## 개요

'공장 다중로봇 관제 시스템' 개념
- 제조 및 물류 현장에서 수십~수백 대의 이기종 로봇(자율주행로봇, 무인운반차 등)을 중앙에서 통합 제어하고 스케줄링하여 생산 효율을 극대화하는 핵심 운영 플랫폼
- 주요 기능: 실시간 모니터링, 작업(배차) 최적화, 충돌 및 교착 방지를 제공하여 생산 효율을 극대화

## 컨셉
- 공장에서 여러 대의 AMR이 동작, 각 AMR은 자신의 배터리 상태를 관제 노드에 보고하고, 관제 노드는 배터리 상태가 20% 이하로 떨어지면, 충전하라는 서비스 지시를 내린다.
    - 모니터링 시: 로봇(자신의 배터리 상태) → 토픽 → 관제(로봇의 배터리 상태 확인)
    - 지시: 로봇(모드 변환해 지시 수행) ← 서비스 ← 관제(충전 모드로 전환 명령)

```
      <로봇> x 100대                                    <관제>
/battery : 자신의 배터리 상태 송출                    /battery 구독
서비스 서버 : 배터리 충전(->100%)                     배터리 잔량에 따라 충전 지시

# 100대 인 경우, 각각의 로봇마다 토픽을 나눠 구분하고, 각각의 상태를 저장 + 각 로봇마다 관리 필요
                                              (DB 관리 필요)

```
## 요구사항
- 현장의 요구
    1. 단일 로봇에 대해
        1. 잘 동작하는지 모니터링
            1. 배터리 상황 파악 : 기준 15% 미만 → 충전 지시
                1. 로봇이 자기의 상태 보고 : *topic 통신*
                2. 상태를 확인(자동) : *subscribe*
                3. 모니터링 → 기준값 이하 로봇 발견 → 충전 지시 : service client
                4. 충전 지시 → 배터리 100으로 변경 : service server

## 작전
1. AMR 노드와 관제 노드 생성
    - AMR 노드: 배터리 상태 보고 → 관제 노드: 각 로봇 배터리 상태 구독
    - 배터리 상태는 초기 100%에서 랜덤하게 소모되도록
2. 충전 지시 내용
    - 관제 노드: 배터리 상태를 보고, AMR 노드에 충전 지시
    - 충전 지시 내리면, 로봇 배터리 상태를 100%로
3. 여러 대 동시 실행
